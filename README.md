# ScienceXpert (SX)

## 🧠 Projet éducatif open-source

**ScienceXpert**, abrégé **SX**, est une plateforme pédagogique gratuite à destination des étudiants du secondaire (Terminale) et du supérieur (1re année post-bac). Le projet vise à offrir un accès équitable au savoir, à travers des ressources structurées, accessibles en ligne.

## 🎯 Objectifs

- Fournir des **cours détaillés**, enrichis de contenus Hors-Programme (HP)
- Proposer des **exercices avec corrigés** pour s'entraîner
- Mettre à disposition des **sujets types examens** pour préparer les évaluations
- Intégrer une section **QCM** filtrable
- Offrir à terme une **IA éducative** (chatbot limité par algorithmes de décision)
